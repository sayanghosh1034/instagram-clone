# Instagram Clone

A responsive **Instagram-inspired website clone** created as part of a hands-on **Git and GitHub tutorial**. The project was developed to practice the fundamentals of web development while learning how to use Git for version control and GitHub for managing and hosting source code.

## Project Overview

This project recreates the basic visual structure and user experience of a modern Instagram-style social media platform. It focuses primarily on frontend development and provides a practical environment for experimenting with HTML, CSS, JavaScript, and Git.

The main purpose of this project is **learning and practice**, rather than building a production-ready social media application.

Through this project, I practiced creating a website, organizing project files, tracking changes with Git, creating commits, connecting a local repository to GitHub, and managing the project using a remote repository.

> **Disclaimer:** This project is an educational clone inspired by Instagram. It is not affiliated with, sponsored by, or endorsed by Instagram or Meta.

## Getting Started

Follow the steps below to run the project locally.

### 1. Clone the Repository

Clone the repository using Git:

```bash
git clone <repository-url>
```

### 2. Navigate to the Project

```bash
cd instagram-clone
```

### 3. Open the Project

Open the `index.html` file in a web browser.

If you are using **Visual Studio Code**, you can also use the **Live Server** extension to launch the project locally.

## Git Commands Practiced

Since this project was created during a Git tutorial, several fundamental Git commands were practiced.

### Initialize a Repository

```bash
git init
```

### Check Repository Status

```bash
git status
```

### Add Files

```bash
git add .
```

### Commit Changes

```bash
git commit -m "Initial commit"
```

### Create a Branch

```bash
git branch feature
```

### Switch Branches

```bash
git checkout feature
```

or:

```bash
git switch feature
```

### Add a Remote Repository

```bash
git remote add origin <repository-url>
```

### Push Code to GitHub

```bash
git push -u origin main
```

### Pull Latest Changes

```bash
git pull origin main
```

These commands were used to understand the basic workflow of managing a project with Git and GitHub.

## Git Workflow

The general development workflow followed for this project was:

```text
Create / Modify Files
        ↓
     git status
        ↓
      git add
        ↓
    git commit
        ↓
    git push
        ↓
      GitHub
```

This workflow demonstrates how Git can be used to track the development history of a project and synchronize local work with a remote GitHub repository.
